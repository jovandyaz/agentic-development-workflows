# Security Policy

## Supported versions

Security fixes are applied to the latest release. Upgrade before reporting a
problem that may already be resolved.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's
[private vulnerability reporting](https://github.com/jovandyaz/agentic-development-workflows/security/advisories/new)
and include the affected command, impact, reproduction steps, and any proposed
mitigation.

Never include real credentials, tokens, or private repository content in a
report. You should receive an acknowledgement within seven days.
